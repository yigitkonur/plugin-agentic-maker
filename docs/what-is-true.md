Run 2026-10-20 on Claude Code 2.1.302, claude.ai subscription auth (`apiKeySource: none`), herdr 0.9.5, macOS. Every row below was observed with a real run in a throwaway plugin (`spike`: one user-invoked skill with hooks, one model-invocable skill, one `user-invocable: false` skill, a failing-`!cmd` skill, one agent, a `bin/` script, a hook that dumps its stdin). Estimated spend for all of it: **USD 0.027** (12 headless runs + 1 eval; Haiku/Sonnet, every run capped by `--max-turns` and `--max-budget-usd`).

Verdicts: **TRUE** (the plan's assumption holds) · **FALSE** (it did not; consequence listed) · **CHANGED** (a better option was found) · **PARTIAL** · **UNVERIFIED** (reason given).

## Findings that are not in the U list

- **E1.** `bin/` is on the **Bash tool's** PATH (`command -v spike-tool` → the plugin's `bin/`) and **not** on a hook process's PATH (`path_has_plugin_bin=False`). Hooks call `${CLAUDE_PLUGIN_ROOT}/bin/agentic-maker`.
- **E2.** In restricted mode, tools outside `--allowedTools` are denied without a prompt and the denial lands in the `result` event's `permission_denials`: a free source of "friction" evidence for the reader.
- **E3.** A non-restricted child runs in the **user's** permission mode (`bypassPermissions` here). `run` always passes `--permission-mode` explicitly and records it.
- **E4.** `claude --restricted` removes `Bash` and other code-running tools unless `--tools` names them, and confines file tools to the working directories; that is the sandbox for the file tools. `Bash` itself is not OS-sandboxed by this flag, so a destructive-capable target still needs fixtures and a throwaway cwd.
- **E5.** `agy` on this machine's PATH is a wrapper that does multi-account rotation on **every launch** (the conductor notes record `agy --version` switching an account). **The plugin never launches `agy`.** It can read an agy session the user already runs (`existing`, or an agy the user started under herdr), with a screen-format adapter marked `documented only`.
- **E6.** A `-p` stream can contain several `init`, `result`, `hook_*` and `background_tasks_changed` events; `normalize` must not assume one of each.
- **E7.** The user's herdr-conductor documents that herdr-managed `claude` and `codex` workers are interactive (never `-p`/`exec`). That governs herdr workers only; the headless runner is a plain subprocess with an exit code, and the docs say so.
- **E8.** The Claude session JSONL for this very session exists at the documented path, so source 1 is available both for the in-session reader (`transcript_path` in hook payloads) and for herdr workers (`agent_session.value`).

## What changes in the plan (applied in this commit to `docs/design/`)

1. §6.2 / §6.5 / Q4: the clean room is the `--restricted` recipe; `eval` is optional; the contamination report comes from `init`.
2. A8 settled: H2 in the `derail` skill frontmatter.
3. §6.6: `belief_source` defaults to `inferred`.
4. §5 / §8: `!`-line lint, `|| true`, hook path via `${CLAUDE_PLUGIN_ROOT}`.
5. §6.2 herdr row and 03 harness notes: agy is never launched; Codex/agy adapters are `documented only` unless the user supplies a live session.
6. §12: the sixteen unknowns now carry these verdicts.
