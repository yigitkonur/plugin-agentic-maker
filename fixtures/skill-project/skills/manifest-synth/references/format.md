# Release notes format

Title line, exactly: `# Release notes — v<version>` (an em dash, then the version from `version.txt`).

Sections, in this order: `## Features`, `## Fixes`, `## Other`. Leave out a section that has no entries.

Entry: `- <Subject with its first letter capitalised> (#<pr>)`, one line, at most 72 characters including the PR number.
